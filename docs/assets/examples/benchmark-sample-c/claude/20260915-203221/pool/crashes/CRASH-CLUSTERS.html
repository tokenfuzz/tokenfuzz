How to read this page

What a row is

A crash is a sanitizer diagnostic reproduced through bin/probe. Two crashes merge when their normalized top frames match — the same rule ClusterFuzz uses — so different inputs into one bug count once. The canonical report is the strongest evidence in the cluster; other members are listed under the report count.

Severity

The CVSS v4.0 score bin/severity computed from the primitive, the surface and how far the audit got toward proving the bug. Pending means the quality gate has not finished; Needs review means the class has no trustworthy CVSS mapping without a human; Not a security report is a real defect retained as engineering evidence that earns no security credit.

Status

accepted passed every gate; pinned was kept by a human marker and bypassed the gate; needs content / needs attention / needs review want a person; pending is an auto-filed skeleton the agent has not finished; stale review means the report changed after its review concluded.

Clock

Each report carries the moment it was filed. The chart places every problem at its first report, on the run's own clock when the run start is known and otherwise from the first report. A problem with no clock is listed but not drawn.

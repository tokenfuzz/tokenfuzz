How to read this page

Where a rejection comes from

trigger-provenance is the source-anchored review that checks whether the claimed trigger is reachable from a public boundary and whether the claimed consequence survives reading the code; its detail names which of the two failed. A reviewer verdict is an independent model's rationale when it voted to reject after the quality gate. A quality-gate reason is recorded when nothing else is.

Claimed severity

The score the report carried before rejection, when it was scored at all. It is shown so an ambitious wrong claim can be told from a modest one; it earns nothing.

Ledgers and hypotheses

Per-cell ledgers list signatures rejected before they became a directory. Discarded hypotheses are the agents' own closed leads, kept because what a model tried and abandoned is part of how it reasons.
